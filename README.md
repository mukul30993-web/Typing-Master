# ⌨️ Typing Master

A modern typing speed test web application built using **Flask, HTML, CSS, JavaScript, and MySQL**. It helps users improve their typing speed and accuracy with a clean and responsive interface.

---

## 🚀 Features

- ⏱️ 60-second typing timer
- 📊 Words Per Minute (WPM) calculation
- 🎯 Accuracy calculation
- ❌ Error highlighting
- 🔄 Restart typing test
- 💻 Responsive user interface
- 🗄️ MySQL database integration

---

## 🛠️ Tech Stack

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- MySQL

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/mukul30993-web/Typing-Master.git
```

2. Open the project folder

```bash
cd Typing-Master
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```

5. Open your browser and visit

```
http://127.0.0.1:5000/
```
